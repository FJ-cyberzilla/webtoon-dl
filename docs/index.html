High-performance, parallel scraper & native PDF compiler written in Go.

Key Capabilities

⚡ High Performance
Worker-pool concurrency pattern downloading multiple pages simultaneously. Static binary compiled in Go with zero runtime dependencies.
🛡️ Industrial-Grade Reliability
Features singleflight request deduplication, memory + disk LRU caching, atomic I/O file operations, and proactive system health probes.
🎨 Branded Terminal UI
Interactive TUI powered by custom styles, color-coded logging, multi-platform selection, and real-time animation updates.
📄 Pure Go PDF Conversion
Native image-to-PDF conversion built without heavy C/C++ bindings (CGO-free) for simple cross-platform deployment.

Quick Start

Build from Source

$ git clone https://github.com/FJ-cyberzilla/webtoon-dl.git
$ cd webtoon-dl
$ make build
$ ./bin/webtoon-dl

Interactive Controls

  • [P] Toggle target platform (Webtoons.com / Comicland.org)
  • [S] Open API Settings Dashboard
  • [Type Title + Enter] Instant comic lookup and automated parsing
  • [Q] / [Ctrl+C] Safely abort operations and save session logs
